# 阿瓦隆笔记本：从代码到上线

这是一套给非技术背景学习者准备的部署实践课。你不需要先学完整套编程知识；我们会从一个已经能运行的项目出发，一边完成部署，一边理解 GitHub、Next.js 和 Vercel 各自负责什么。

## 你会完成什么

课程结束时，你将拥有：

- 一份属于自己的 GitHub 项目副本
- 一个能在本地运行的 Next.js 应用
- 一个由自己的 Vercel 账号管理的线上站点
- 一条“修改代码 → 推送 GitHub → 自动生成新部署”的工作流
- 一套判断部署问题发生在哪一层的排查方法

## 整条路线

```text
原项目
  ↓ Fork
你的 GitHub 仓库
  ↓ Clone
你的电脑
  ↓ Import
你的 Vercel 项目
  ↓ Deploy
线上网址
```

把它想成出版一本书：GitHub 保存书稿，电脑是你的编辑桌，Vercel 是印刷和发行系统，线上网址则是读者拿到的成品。

## 开始前准备

- 一个 GitHub 账号
- 一个 Vercel 账号，建议直接使用 GitHub 登录
- 电脑已安装 Git 和 Node.js
- 可以使用终端执行命令

第一次接触这些名词也没关系。每一章都会解释当前步骤的目的，并给出完成后的检查点。

## 最重要的规则

请使用自己的 GitHub Fork 和自己的 Vercel 项目练习，不要直接修改原项目。这样每位学习者都有独立环境，可以安全地尝试、出错和重新部署。

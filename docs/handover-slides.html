Acceptance · Scope

验收状态与范围边界

已验收

  • MVP 核心流程完成
  • ESLint 零告警
  • TypeScript 与生产构建通过
  • 构建及部署路径问题已修复

已接受的 MVP 边界

  • 暂不支持自定义玩家昵称
  • 暂不区分远征投票与组队投票
  • 暂不开放首页继续对局入口
范围边界不是被遗忘的缺陷，而是明确记录、共同接受的取舍，不阻塞当前版本结项。
